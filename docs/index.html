Retro PlayApp guide
GUIDE Everything you can do, explained simply

Your retro games, tidy and ready to play

Retro Play Game Manager keeps your game archive in order: you add games, fix titles and covers, and with one click you install them where you play, on ES-DE or on a MiSTer FPGA. Every page of this guide explains one task and shows it to you in an animation.

Start here

How it works, in three words

01

The archive

A folder (on your PC, on a USB drive or on a NAS) that keeps your games and everything that describes them: titles, dates, covers, videos, saves.

02

The app

Retro Play Game Manager opens the archive and shows it like a game store: you search, fix, complete and delete. Every change ends up in the archive.

03

The frontend

The program you play on: ES-DE on your PC or a MiSTer FPGA in the living room. The app installs games there, removes them and starts a game for you.

Good to know

  • You can also drag the archive’s folder onto the window, or press Ctrl O.
  • The archives you opened recently are on the start page: one click and you are back.
  • The archive can be anywhere: on your PC, on a USB drive or on a NAS.
  • When you open it again, the app goes back to the system and the sorting you had.

Watch out

The app only opens archives in the current Retro Play format. An archive made by a very old version is refused and has to be made again.

  1. Click Add games, at the top of the sidebar.
  2. Choose the platform: type a few letters to find it (the ones the archive already has come first).
  3. Click Choose the folder and pick where the ROMs are. If the folder is named like the system (e.g. snes), the platform is picked for you.
  4. Check the summary: how many games, how much space, the ones already there and the files left out. Then press Copy.

Good to know

  • The app adds only the files ES-DE recognises for that platform: the others (a readme.txt…) are left out, and it tells you.
  • Games on several discs (.cue, .m3u, floppies Disk 1 of 3…) become one game.
  • Games with the same title become the versions or formats of one game (e.g. USA and Europe): in the window you can separate them or join them by hand. See Versions and formats.
  • A game already in the archive is not touched.
  • The arrow next to Add games also imports a .zip export, or the games only the frontend has.

  1. The archive is a normal folder: on your PC, on a drive or on a NAS.
  2. The games stay as they are, split by system and by kind of file (snes/sfc/, amiga/lha/…).
  3. In @metadata there is everything that describes them.
  4. The details (title, description, dates, developer, rating…) in small files, plus a gamelist.xml that ES-DE reads too.
  5. The media: covers, back covers, 3D boxes, screenshots, logos, fan art, videos and PDF manuals.
  6. In @saves the copies of your saves, one for each time you archived them.
  7. In @dats the DATs you gave each system.
  8. In @collections the collections (the app reads them and tells you which ones a game is in).

Why it is made like this

  • The games stay normal files: you copy them, move them and use them even without the app.
  • Each change rewrites a small file, so even a huge archive on a NAS stays fast.
  • The app always writes safely: a new file takes the place of the old one only once it is complete. If another PC changed the same game meanwhile, the app asks before overwriting.

How a version is recognised

  • From the tags in brackets of the name: Zelda (USA).nes and Zelda (Europe).nes are two versions.
  • Different kinds of file with the same tags are formats of the same version: Game (USA).cue and Game (USA).chd.
  • A name that tells a version (v1.2, Rev 1…) never goes with one telling another.
  • When installing you choose version and format; MiSTer FPGA, which doesn’t load LHAs, gets the first format it can load.

Resuming from a save

  • When the archive has a newer save, the section says The archive has a newer one, with Resume. Each copy also has Bring to the frontend, Show in folder and Delete.
  • Before bringing a copy back, what the frontend has and the archive doesn’t is archived: nothing is lost.
  • To resume (sidebar) lists the games with newer saves in the archive; the button at the top resumes them all.

Good to know

  • It works with RetroArch (for ES-DE) and with the cores of MiSTer FPGA.
  • A copy goes back whole to the same emulator. Between RetroArch and MiSTer only the game save goes over, and only for NES, Super Nintendo, Game Boy and Game Boy Color.
  • If RetroArch is open, saves aren’t brought back (closing, it would write its own over them).
  • Uninstalling a game archives its saves first; installing it, when the frontend has none, brings back the latest.
  1. Select the games and click Export (or from the archive’s menu, or from the … menu for all those shown).

The states

  • Verified all the game’s files are in the DAT (under any name).
  • Bad dump the DAT says one of its files is.
  • Differs from the DAT some files aren’t in the DAT, or something is missing (a track, a ROM).
  • Not in the DAT, Unverifiable (a 7z, a CHD), To verify (changed or never verified).

Archive

The folder that keeps your games and everything that describes them. What it looks like.

Frontend

The program or system you play on: ES-DE, MiSTer FPGA.

ES-DE

EmulationStation Desktop Edition: the PC frontend that starts the emulators.

MiSTer FPGA

Hardware that recreates consoles instead of emulating them. Its games live on its SD card.

ROM

The file of a game (a cartridge, a disc, a floppy).

Metadata

Everything that describes a game: details and media.

Details

Title, description, release date, developer, publisher, genre, players, rating.

Media

Covers, back covers, 3D boxes, physical media, screenshots, logos, fan art, videos, manuals.

Marquee

The game’s logo, on a transparent background.

Fan art

A large picture of the game: on its page it is the background, heavily blurred.

Scraping

Getting details and media automatically from an online service (ScreenScraper).

Completeness

How many details and media a game has, as a percentage.

Version

A variant of the same game: USA, Europe, Rev 1, v1.2…

Format

A kind of file of the same game: LHA or ADF, CUE or CHD, ZIP…

ROM Set

The arcade games of one MAME version (e.g. 0.289).

DAT

The list of a system’s good dumps (No-Intro, Redump, MAME), to check your files.

CRC

A fingerprint of the file: two files with the same CRC and size are the same.

Export

A .zip file with games, to import into another archive.

To archive

A game only the frontend has, not the archive.

To update

A game the frontend has with files different from the archive’s.

Save

A game’s progress: the game save and the emulator’s save states.

MCP

The protocol an AI assistant uses to work with the app’s tools.

If I edit a game in the app, does it change in ES-DE too?

Not by itself: changes go into the archive. The game shows as different from the installed one and, when you install it again, ES-DE gets the updated details and media.

Can I use the archive from several computers?

Yes, for example from a NAS. The app rewrites only the files it changes, and if another PC changed the same game meanwhile it asks whether to reload or overwrite. F5 reads again the parts that changed.

Does uninstalling a game delete it?

No: it only removes it from the frontend. It stays in the archive, and its saves are archived first. To delete it from the archive, use Delete from the archive.

Why does a game say «Cannot be installed»?

The frontend can’t take it: it doesn’t have that system, none of the game’s formats is one of its compatible formats (e.g. MiSTer doesn’t load LHAs, unless you add them), or it is an arcade game of a ROM Set the frontend doesn’t use. The tooltip says why.

Do I need an account for scraping?

For automatic scraping yes, a ScreenScraper account. To look media and details up on the web by hand, no: there are also libretro thumbnails and Wikipedia, with no account.

Can I lose my saves?

The app is made not to lose them: a copy in the archive is never overwritten, and before bringing one back to the frontend it archives what the frontend has and the archive doesn’t.

What languages is the app in?

English and Italian: you choose in the Settings, General page.

Windows warns me the first time I start it, is that normal?

Yes: the program isn’t signed, so SmartScreen may ask for confirmation the first time.
