GUIDE Everything you can do, in short

Your retro games, tidy and ready to play

Retro Play Game Manager keeps your games in order: you add them, fix titles and covers, and install them with one click on ES-DE, MiSTer FPGA, RetroArch, RetroPie or Batocera. Each page explains one task and shows it in an animation.

How it works

01

The archive

The folder with your games and everything that describes them: titles, covers, videos, saves. On your PC, a drive or a NAS.

02

The app

Shows the archive like a game store. Here you search, fix and complete: every change goes into the archive.

03

The frontend

Where you play: ES-DE or RetroArch on your PC, a MiSTer FPGA, a RetroPie or a Batocera. The app installs games there and starts them.

Watch out

An archive made by a very old version of the app doesn’t open: it has to be made again.

  1. Click Add games, at the top of the sidebar.
  2. Choose the platform: type a few letters to find it.
  3. Click Choose the folder and pick where the ROMs are. If the folder is named after the system (e.g. snes), the platform is picked for you.

  6. Done. From here you can start scraping to get titles and covers.
  7. The games are in the sidebar, under their system.

Good to know

  • Only the files ES-DE recognises for that platform are copied.
  • A game on several discs becomes one game. Games with the same title become versions of one game.
  • Games already in the archive are not touched.
  • The arrow next to Add games also imports a .zip export, or the games only the frontend has.

Why it is made like this

  • The games stay normal files: you can use them without the app.
  • Each change rewrites only a small file, so even a huge archive on a NAS stays fast.
  • If another PC changed the same game, the app asks before overwriting.

A kind of file of the same game: LHA or ADF, CUE or CHD, ZIP… Two versions both in ZIP are one format.

The arcade games of one MAME version (e.g. 0.289).

The list of a system’s good dumps, to check your files.

A file’s fingerprint: two files with the same CRC are the same.

The protocol an AI assistant uses to work with the app’s tools.

If I edit a game in the app, does it change in ES-DE too?

Not right away: the change goes into the archive. ES-DE gets it when you install the game again.

Can I use the archive from several computers?

Yes, for example from a NAS. If two PCs change the same game, the app asks what to do. F5 reads the archive again.

Does uninstalling a game delete it?

No, it only removes it from the frontend: it stays in the archive. To delete it, use Delete from the archive.

Why does a game say «Cannot be installed»?

The frontend can’t load it: it doesn’t have that system, it takes none of the game’s formats (see Compatible formats), or it is an arcade game of another ROM Set. The tooltip says why. When it’s only the format, Install anyway installs it all the same.

Do I need an account for scraping?

For automatic scraping yes, a ScreenScraper account. To look things up on the web by hand, no.

Can I lose my saves?

No: the copies in the archive are never overwritten, and before bringing one back the app archives the frontend’s.

What languages is the app in?

English, the default, and Italian: switch in Settings → General → Language.

How do I update the app?

It does it by itself: at start it downloads and installs the new version. See Updates.

Windows warns me the first time I start it, is that normal?

Yes: the app isn’t signed, so the first time SmartScreen asks for confirmation.
