Tool MCP

Tutti i tool che l’app dà a un assistente AI col suo server MCP: cosa fa ognuno, in parole semplici, e una domanda che lo fa usare all’assistente.

Come si usano

  • Accendi il server e collega il tuo assistente: vedi Server MCP per l’AI.
  • I tool non li chiami tu: chiedi con parole tue e l’assistente li sceglie. Le domande sono esempi: un clic ne copia una.
  • Lo stesso elenco è nell’app, in Impostazioni → Server MCP → Mostra i tool.

Sicurezza

  • I tool segnati Solo lettura guardano soltanto. Quelli segnati Fa modifiche cambiano l’archivio, il frontend o un file, e ogni modifica la vedi nella finestra.
  • Per eliminare giochi, o installarli, disinstallarli e importarli, l’assistente prima ti mostra il piano e serve la tua conferma.
