Valori e condizioni

Ciò che un elemento dice viene dal gioco col focus, dalla schermata o dal tema, tra graffe; quando si vede, dalle sue condizioni.

{ "type": "text", "text": "{focus.systemName|upper} · {focus.year}" }
{ "type": "text", "text": "{t.desk.gamesN n=screen.count}" }
{ "type": "text", "text": "{focus.var.tagline}", "when": { "has": "focus.var.tagline" } }
{ "type": "box", "class": "crt", "when": { "option": { "crt": true }, "not": { "aspect": "narrow" } } }
ValoreCos’è
focus.…, item.…, game.…Il gioco col focus, la voce disegnata, il gioco della pagina: name, systemName, year, release, developer, publisher, genre, players, rating, played, playTime, blurb, desc, var.…; un sistema: title, count; un percorso: title, author, description, steps, available; una tappa: i valori del gioco e note, number, total, available, missing
screen.…La schermata: title, count, query, empty; un percorso: by, description
var.…, opt.…, t.…, app.…I valori del tema, le sue opzioni, le parole dell’app (t.desk.home.played), l’ora e la data

Filtri dopo |: upper, lower, year, date, number, games (12 → “12 giochi”), ago, duration, default:…, prefix:…, suffix:…, max:….

when mostra un elemento solo se vale tutto ciò che dice: variant, option, system, focus (game, system, journey, step…), has (un valore che c’è), aspect (narrow 4:3, normal, wide 21:9), not.
