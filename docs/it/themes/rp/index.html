Il riferimento di rp

rp è il modo in cui la pagina di un tema parla con l’app. I suoi tipi sono in rp.d.ts, accanto ai tuoi temi.

Cosa dice

ProprietàCos’è
rp.kind'effect', o 'screen' per un elemento pagina con input
rp.screen, rp.paramsLa schermata in cui sta, e con cosa è stata aperta
rp.activeLa pagina ha il joypad
rp.lang, rp.theme, rp.optionsLa lingua dell’utente, il tema, le sue opzioni
rp.focus, rp.nowIl gioco o sistema col focus; la sezione e la schermata mostrate
rp.readyUna promessa, quando tutto questo è pronto

Cosa fa

ChiamataCosa fa
rp.games(query)I giochi: { total, items }. Query: only (favorites, installed, recent, played), system, query (parole), similar, installed, collection, offset, limit (100, fino a 500)
rp.game(id)Un gioco con la descrizione e tutte le immagini e i video (media)
rp.systems(), rp.collections()I sistemi coi loro numeri; le collezioni
rp.open(target)Le schermate dell’app: { game, list }, { games, title }, una sezione, 'menu', 'spin', 'attract'
rp.back()Chiude la schermata in cima, o torna alla Home
rp.play(id, { resume }), rp.install(id)Avvia il gioco; il pannello dell’app che lo installa (che chiede all’utente)
rp.favorite(id, on)Lo mette nei preferiti o lo toglie; com’è adesso
rp.take(actions), rp.hints(list)I tasti che la schermata prende; cosa fanno, in fondo
rp.focusTabs(), rp.spot(id)Il focus su alla barra; cosa mostra lo sfondo
rp.sound(name), rp.text(key, vars)Un suono della Desktop Mode (prima quello del tema); le parole dell’app nella lingua dell’utente
rp.systemArt(name)La console disegnata dall’app, come indirizzo di un’immagine
rp.store.get(key), rp.store.set(key, value)Un po’ di dati del tema, tenuti su questo computer (64 KB per chiave)
rp.url(file)Un file del tema, dal suo percorso nella cartella del tema

Cosa sente

rp.on(…)Quando
'input'Un tasto che la schermata prende, mentre ha il joypad: { action, repeat } (con 'text' preso, { action: 'text', text } ed 'erase')
'press'Qualsiasi tasto, chiunque lo prenda
'active', 'focus', 'screen'La schermata ha il joypad o no; il gioco o sistema col focus; cosa è mostrato
'launch'Un gioco che si avvia, avviato o fallito ({ state, game }), poi null
'options', 'lang'L’utente ha cambiato le opzioni o la lingua

Un gioco ha: id, name, system, systemName, year, releasedate, developer, publisher, genre, players, rating (da 0 a 5), cover, screenshot, favorite, installed, playedAt, playTime, blurb, hue. Tasti: up down left right ok back x y lb rb lt rt menu view.
