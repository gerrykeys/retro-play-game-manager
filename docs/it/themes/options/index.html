theme.json

Opzioni per l’utente

Lascia che chi usa il tuo tema lo cambi: un CRT acceso o spento, un colore d’accento, quanto bagliore.

"options": [
  { "id": "crt", "type": "toggle", "label": { "en": "CRT lines", "it": "Righe CRT" }, "default": true },
  { "id": "sky", "type": "select", "label": "Cielo", "default": "sunset",
    "choices": [{ "value": "sunset", "label": "Tramonto" }, { "value": "night", "label": "Notte" }] },
  { "id": "accent", "type": "color", "label": "Accento", "default": "#4fb3ff" },
  { "id": "glow", "type": "range", "label": "Bagliore", "min": 0, "max": 40, "step": 4, "default": 18, "unit": "px" }
]

L’utente le cambia nella Desktop Mode: Menu → Tema, poi Opzioni del tema (RB). Il tuo tema le legge:

/* Un interruttore: l'attributo quando è acceso */
.rp-desk[data-opt-crt]::after { content: ''; /* … */ }
/* Una scelta: l'attributo col suo valore */
.rp-desk[data-opt-sky='night'] .rp-backdrop { filter: brightness(0.6); }
/* Tutte: una variabile (un colore, un numero con la sua unità, 1 o 0, una scelta tra virgolette) */
:root { --rp-accent: var(--opt-accent); }
.rp-hero-title { text-shadow: 0 0 var(--opt-glow) var(--rp-accent); }

In uno script: rp.options, e rp.on('options', …) quando cambiano.
