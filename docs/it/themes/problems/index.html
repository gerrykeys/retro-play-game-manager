Quando qualcosa non va

Un tema con errori mostra ciò che può; un avviso dice quanti sono, F9 dice cosa e dove.

L’avviso diceCosa fare
theme.json non è JSON validoUna virgola di troppo o mancante, chiavi senza virgolette: la riga è indicata. Il JSON non ha commenti.
Chiave sconosciutaSpesso un refuso: viene suggerita la chiave più probabile.
Il file non è nel temaControlla il percorso dalla cartella del tema e le maiuscole.
Non è una parte della Desktop ModeUna classe .rp-… che non esiste: viene suggerita la più vicina, F9 mostra quelle vere.
Non è permesso@import o un indirizzo della rete: metti il file nel tema.
«api» deve essere 2Il tema è stato fatto per un’altra versione del formato.
Il mio CSS non fa niente

F9 sulla parte: è il nome che hai scritto? Una regola su un elemento nascosto dall’app (.rp-card-title) richiede display: block. Ciò che l’app imposta sull’elemento stesso (il posto di una card) richiede !important, oppure spostalo con transform.

Un’immagine o un carattere non si vede

Il percorso parte dalla cartella del tema in theme.json e dalla cartella del file CSS nel CSS; le maiuscole contano. Un carattere in fonts vuole un file .woff2, .woff, .ttf o .otf.

La mia pagina non riceve il joypad

Dai all’elemento pagina "input": true, poi chiama rp.take([...]) coi tasti che usa, dopo rp.ready. Gli altri vanno alla Desktop Mode.

Il mio script non carica una libreria

Le pagine dei temi non hanno rete: copia il file della libreria nella cartella del tema e caricalo da lì.
