Script

Elementi pagina

Il livello più profondo: una pagina tua, coi tuoi script, dove vuoi in una scena, coi giochi e i pulsanti dell’app.

"scenes": {
  "home": { "elements": [
    { "type": "page", "src": "pages/home.html", "input": true, "pos": [0, 0], "size": [100, 100] }
  ] }
}

Senza input la pagina disegna e ascolta soltanto (un visualizzatore accanto a una lista). Con input prende il joypad mentre ha il focus, e dice quali tasti prende; gli altri vanno alla scena e alla Desktop Mode (LB e RB le sezioni, Menu il menu, B indietro). rp.params: sui giochi { query, title }, sulla pagina di un gioco { id }.

rp.ready.then(async () => {
  rp.take(['up', 'down', 'ok', 'x'])
  const { items } = await rp.games({ only: 'played', limit: 30 })
  let at = 0
  disegna(items, at)
  rp.hints([{ action: 'ok', label: await rp.text('desk.hint.details') }, { action: 'x', label: await rp.text('shelf.play') }])
  rp.on('input', ({ action }) => {
    if (action === 'down') disegna(items, ++at)
    else if (action === 'up' && at === 0) rp.focusTabs()
    else if (action === 'up') disegna(items, --at)
    else if (action === 'ok') rp.open({ game: items[at].id, list: { only: 'played' } })
    else if (action === 'x') items[at].installed ? rp.play(items[at].id) : rp.install(items[at].id)
  })
})

Da sapere

  • I tasti e la rotellina della pagina vanno alla Desktop Mode: F10 esce sempre.
  • rp.take(['text']) dà alla pagina le lettere scritte (una ricerca tua).
  • Lascia spazio alla barra in alto (circa l’11% dell’altezza), o lascia tabs fuori dalla cornice.
