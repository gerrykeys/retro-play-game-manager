Gli elementi

Ogni elemento ha un tipo, e mostra il gioco o sistema col focus (o il gioco della pagina, o la voce della lista in cui è disegnato).

TipoCos’è
textParole con valori dentro: "{focus.name}" (valori). scroll: lo stick destro lo scorre; more: Visualizza lo apre intero
imageUn’immagine del gioco (media: cover, screenshot, titlescreen, marquee, fanart, 3dbox, miximage…, o una lista provata in ordine) o un file del tema (src); fit, pixelated, fallback, video (il suo video dopo una pausa), fly. Sfuma quando il focus si muove
videoIl video del gioco, quando il focus si ferma su di lui
listI giochi, sistemi o immagini tra cui si muove il focus (liste)
buttonsGioca (o installa, riprendi, ciò che serve al gioco), dettagli, preferito, immagini, simili
groupElementi insieme; scroll: "focus" li fa scorrere perché quello col focus venga per primo; rekey ripete le loro animazioni a ogni gioco
meta, rating, badgesUna riga di dati (anno, sviluppatore, genere…), le stelle, le etichette (installato, giocato, preferito…)
systemArt, logo, icon, clock, boxLa console di un sistema, il logo dell’app, un’icona, l’ora, un riquadro per il tuo CSS
dots, positionUn punto per voce di una lista; “4 / 120”
keyboard, fieldLa ricerca: la sua tastiera, le parole scritte
tabs, brand, status, hintsLa cornice: le sezioni, il logo, il frontend e l’ora, i tasti
pageUna pagina del tema coi suoi script (elementi pagina)
shelvesLe file della Home di default

Ogni elemento può avere id, class, pos, size, origin, rotate, z, opacity, style, when (condizioni) e of (la lista di cui mostra il focus).
