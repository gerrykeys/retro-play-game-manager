Il tuo primo tema in 5 minuti

Dalle impostazioni a un tema tutto tuo, visto dal vivo.

  1. Apri Impostazioni → Aspetto e, in Temi della Desktop Mode, fai clic su Nuovo tema.
  2. Dagli un nome e fai clic su Crea e apri: la Desktop Mode si apre col tuo tema, con l’editor accanto.
  3. Cambia i colori, i caratteri, gli angoli, lo sfondo, e in Disposizione scegli un layout per ogni schermata (un coverflow, una ruota, una dashboard…): ogni modifica si vede subito ed è salvata in theme.json.
  4. Fai clic su theme.css in fondo all’editor: si apre nel tuo editor (VS Code, Blocco note…). Aggiungi una regola e salva.
  5. Premi F9: l’ispettore dice il nome di ciò che sta sotto il puntatore o ha il focus, e il selettore da copiare.

Una prima regola, per theme.css:

/* I titoli delle file in maiuscolo, un po’ distanziati */
.rp-list-title {
  text-transform: uppercase;
  letter-spacing: 0.1em;
}

/* La card col focus un po’ più grande */
.rp-card.is-focused {
  transform: scale(1.14);
}

Da sapere

  • F5 rilegge il tema; F10 esce dalla Desktop Mode.
  • In VS Code, theme.json completa e spiega ogni chiave mentre scrivi (nomina lo schema accanto ai tuoi temi).
  • Un errore non rompe mai il tema: ciò che è sbagliato viene lasciato fuori, e un avviso dice dove (Quando qualcosa non va).
