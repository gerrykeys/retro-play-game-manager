La cartella del tema

Tutto ciò che un tema ha sta nella sua cartella, trovato col percorso da lì.

themes/
  theme.schema.json      lo schema di theme.json, per il tuo editor (lo scrive l'app)
  rp.d.ts                i tipi di rp, per gli script (lo scrive l'app)
  il-mio-tema/
    theme.json           cos'è il tema e cosa cambia (necessario)
    theme.css            il suo CSS (facoltativo; più file con "styles")
    preview.webp         la sua immagine nella lista dei temi, 16:9
    systems.json         ciò che ogni sistema ha di suo (messo dentro da "include")
    fonts/  images/  sounds/  videos/  systems/
    effects/stelle.html  una pagina di script disegnata come livello
    pages/home.html      una pagina di script messa in una scena
  • I percorsi usano / e partono dalla cartella del tema: "images/sfondo.webp". Nel CSS, url(images/sfondo.webp) parte dalla cartella del file CSS.
  • I nomi devono coincidere esattamente, maiuscole comprese: Logo.PNG non è logo.png.
  • Un tema usa solo i suoi file: nessun indirizzo della rete, nessun file altrove sul computer. Funziona offline, e non può tracciare nessuno.
  • Immagini: png, jpg, webp, avif, gif, svg. Caratteri: woff2, woff, ttf, otf. Suoni: ogg, mp3, wav, flac, m4a. Video: mp4, webm.

Condividere un tema

Ogni tema della lista ha Esporta .zip; Importa .zip ne aggiunge uno ai tuoi (il suo theme.json in cima allo zip, o in una cartella). Niente di uno zip viene mai scritto fuori dalla cartella del nuovo tema.
