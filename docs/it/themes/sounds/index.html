Suoni e musica

Ogni suono della Desktop Mode può essere tuo, anche senza file.

"sounds": {
  "move": { "synth": { "wave": "square", "freq": 1046, "to": 988, "dur": 0.03, "gain": 0.012 } },
  "ok": "sounds/ok.ogg",
  "back": { "file": "sounds/indietro.wav", "volume": 0.6 },
  "edge": false,
  "volume": 0.8
},
"music": { "src": ["music/1.ogg", "music/2.ogg"], "volume": 0.35, "shuffle": true }
SuonoQuando
moveIl focus si sposta
tabUn’altra sezione, un salto a una lettera
ok, backApri, conferma; indietro
edgePiù in là non si va
openSi apre un menu o un pannello
favorite, unfavoriteMesso nei preferiti, o tolto
launch, errorUn gioco si avvia; qualcosa è andato storto
tick, winLa ruota di Cosa gioco oggi che gira, e ferma

synth è una nota, o una lista fino a 16: wave (sine, square, triangle, sawtooth), freq in Hz, to l’altezza a cui scivola, dur e delay in secondi, gain (0.03 è circa quello dell’app). Una lista suona come un accordo o, coi ritardi, come un jingle.

La musica si ferma mentre si gioca, mentre un video parla (la pagina di un gioco, l’attract mode, l’intro) e con l’interruttore Musica del tema del menu.
