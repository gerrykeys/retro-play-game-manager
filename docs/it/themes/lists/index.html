Liste

Una lista disegna le sue voci e ci muove il focus: il joypad sa sempre dove andare.

/* Un coverflow */
{ "type": "list", "source": "screen", "layout": "row", "scroll": "focus", "anchor": 0.5,
  "width": 24, "ratio": "3:4", "spacing": 14, "tilt": 52, "scale": 1.1, "fade": 0.13 }

/* Una ruota che gira attorno a un punto lontano a destra */
{ "type": "list", "layout": "wheel", "wheel": { "angle": -12, "origin": [4.6, 0.5] }, "scale": 1.2 }

/* Righe tue: l'anno e il nome */
{ "type": "list", "layout": "column", "height": 6,
  "item": { "elements": [ { "type": "text", "text": "{item.year}" }, { "type": "text", "text": "{item.name}" } ] } }
ChiaveCosa fa
sourcescreen (quelli della schermata), played, favorites, installed, recent, discover, today, all, systems, media (le immagini della pagina), similar, journeys, "system:snes", "collection:I miei preferiti", "journey:Il mio percorso" (le sue tappe); fallback: un’altra quando non ha niente
layoutrow, column, grid (columns, rowGap), wheel, path (lungo una linea che serpeggia, accesa fino al focus, dalla partenza al traguardo; wave: quanto serpeggia)
itemcard, line, plate (una console con le sue copertine a ventaglio), shot, node (un’immagine rotonda col suo numero: una tappa), journey (la card di un percorso), o elementi tuoi; art: l’immagine della card
width, height, ratio, gap, spacingMisure in unità; uno spacing minore della larghezza le sovrappone
scroll, anchor, lead, crossfocus: il focus resta ad anchor (da 0 a 1) e le voci scorrono; edge: restano finché il focus non arriva al bordo
scale, fade, tilt, wrapLa voce col focus più grande; le altre più tenui, o girate in 3D; dall’ultima alla prima
title, icon, count, empty, limit, moreUn titolo, cosa dice quando è vuota, la card che le apre tutte

Oltre il bordo di una lista, il focus va all’elemento che trova in quella direzione sullo schermo. La voce su cui una lista ha il focus è focus per gli altri elementi; of nomina la lista.

Da sapere

  • La lista decide il posto di ogni voce (left, top): transform, translate, scale e rotate restano tuoi, con --rel e --dist.
