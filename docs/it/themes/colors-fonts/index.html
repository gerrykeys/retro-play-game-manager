theme.json

Colori, caratteri, angoli

Il modo più rapido per fare tua la Desktop Mode.

colorsVariabile CSSDove
bg--rp-bgDietro a tutto
ink, ink2, ink3--rp-ink, --rp-ink-2, --rp-ink-3Il testo, il testo meno importante, il testo tenue
accent, accent2--rp-accent, --rp-accent-2, --rp-gradIl focus, i pulsanti, la barra sotto la sezione; il gradiente dei due
onAccent--rp-on-accentIl testo sopra l’accento
ok, warn, danger--rp-ok, --rp-warn, --rp-dangerInstallato; preferiti e avvisi; errori
glass, line--rp-glass, --rp-lineI pannelli sopra le immagini e i loro bordi
card, panel--rp-card, --rp-panelCard senza immagine; menu e finestre

Va bene qualsiasi colore CSS: "#ff2bd6", "rgb(255 43 214 / 0.8)", "oklch(70% 0.2 330)". Il tuo CSS può impostare le stesse variabili (:root { --rp-accent: … }): il CSS vince su theme.json, e così un’opzione che cambia i colori è facile.

Caratteri

"fonts": {
  "text": "Segoe UI",                       un carattere del computer o dell'app
  "display": "fonts/Orbitron.woff2",        un file del tema
  "mono": [{ "file": "fonts/Mono-Regular.woff2", "weight": "400" },
           { "file": "fonts/Mono-Bold.woff2", "weight": "700" }]
}

text è quasi tutto il testo, display i titoli, l’ora e i nomi grandi, mono i numeri. Nel CSS: var(--rp-font-text), var(--rp-font-display), var(--rp-font-mono). Quelli dell’app: Plus Jakarta Sans Variable, Space Grotesk Variable, JetBrains Mono Variable.

Angoli

"radius": 0 per angoli vivi, 1.4 di default, fino a 12. In unità (vedi Il CSS di un tema); nel CSS var(--rp-radius).
