Le parole dell’app

Ogni parola della Desktop Mode ha una chiave: texts le dà altre parole, per lingua.

"texts": {
  "desk.tabs.home": { "en": "Start", "it": "Inizio" },
  "desk.home.played": "Continua",
  "desk.gamesN": { "en": "{n} carts", "it": "{n} cartucce" }
}

Ciò che sta tra graffe ({n}, {name}…) è ciò che l’app mette lì. Per trovare una chiave: F9, poi Chiavi dei testi: ogni parola della Desktop Mode mostra la sua chiave al suo posto.
