theme.json

Sfondo e immagini

Immagini e video del tema, dietro a tutto e al posto dei disegni dell’app.

"background": {
  "image": "systems/{system}.webp",   uno per sistema…
  "fallback": "images/sfondo.webp",   …e questo per gli altri
  "video": "videos/loop.mp4",          a ciclo, senza audio
  "gameArt": false,                    non l'immagine del gioco sfocata dietro
  "dim": 0.3,                          da 0 a 1: più scuro
  "blur": 2                            quanto è sfocata l'immagine del gioco, in unità
},
"art": {
  "system": "console/{system}.png",   al posto della console disegnata
  "logo": "loghi/{system}.svg"        al posto del nome del sistema
}

{system} è il nome ES-DE del sistema: snes, megadrive, amiga, arcade… Un ROM Set (arcade/0.289) prende il file della sua piattaforma. Un sistema senza il suo file tiene quello di default.

L’intro

"intro": { "video": "videos/avvio.mp4" }                suona col suo audio, poi la Desktop Mode
"intro": { "image": "images/logo.png", "duration": 2500, "sound": "sounds/avvio.ogg" }
"intro": false                                            niente intro

"logo": true tiene il logo e il nome dell’app sopra la tua immagine. Il CSS lo stila come .rp-intro, e così puoi scrivere un’intro anche solo col CSS.
